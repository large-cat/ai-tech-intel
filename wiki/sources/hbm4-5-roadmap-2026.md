## 一、后 HBM3E 时代：存储的结构性分裂

2025 Q3 市场呈现「冰火交织」：
- **HBM**：燃烧的极热之地，但已现价格分化
- **传统 DRAM**：服务器领涨，消费电子小拖后腿
- **NAND Flash**：复苏步伐明显慢于 DRAM

### HBM3E 价格分化信号
- 12-hi HBM3E（顶级训练集群）：价格坚挺
- 8-hi HBM3E（次级市场）：Q3 已出现 **5-10% 回调**
- 紧缺度边际缓解：美光产能释放，但顶级规格仍一货难求

## 二、HBM4（2026-2027）：规格锁定，格局初定

### JEDEC 标准核心参数

| 参数 | HBM3E | HBM4 | 变化 |
|------|-------|------|------|
| I/O 宽度 | 1024-bit | **2048-bit** | 翻倍 |
| 单颗数据速率 | ~6.4 Gbps | **8 Gbps** | +25% |
| 单堆栈带宽 | ~1.2 TB/s | **>2 TB/s** | 翻倍 |
| 单堆栈容量 | 24-36GB | **36GB (12-Hi) → 48GB (16-Hi)** | 大幅提升 |
| 封装方案 | CoWoS-S | **CoWoS-L + MR-MUF** | 新主流 |

### Base Die 的「主动记忆体」化

HBM4 的关键演进：**Base Die 集成更多逻辑功能**
- 错误校正码（ECC）
- 更复杂的电源管理
- 从「被动记忆体」向 **「主动记忆体」** 演进

这意味着 Base Die 的定制化需求将大幅上升——恰好是台积电的绝对主场。

### 量产时间表
- **SK 海力士**：已向核心客户送出 12-hi HBM4 样品，目标 **2026 下半年量产**
- **美光**：紧随其后
- **三星**：关键取决于 1c nm DRAM 制程能否成功应用于 HBM4，以及热管理问题能否解决——这是其翻盘的最后机会

## 三、HBM4E / 客制化 HBM（2028~）：产业秩序的终极重构

### 技术路线图

| 代际 | 时间 | 关键技术 | 性能目标 |
|------|------|---------|---------|
| HBM4 | 2026-2027 | 2048-bit I/O, CoWoS-L, Base Die 逻辑化 | 2 TB/s, 48GB |
| HBM4E | 2028~ | 数据速率 **9-10 Gbps**, Hybrid Bonding 混合键合 | 更高堆叠（20-Hi+） |
| HBM5 / 3D DRAM | 2028-2030 | **3D DRAM** 技术落地 | 根本性革新 |

### Hybrid Bonding 混合键合
- 可能在 HBM4E 或 HBM5 引入
- 实现更低功耗、更高堆叠层数（**20-Hi 以上**）
- Wafer-to-Wafer 键合，延迟更低、密度更高

### 3D DRAM：根本性解决方案

当平面缩放（2D Scaling）逼近物理极限：
- **三星**：沿用 6F2 结构的 **VS-CAT** 方案
- **SK 海力士**：基于 **IGZO** 的 **4F2 结构** 方案
- 目标：**2028-2030 年商业化**

将 Cell Array 像 3D NAND 一样垂直堆叠，被视为 DRAM 与 HBM 的终极演进方向。

## 四、客制化趋势：从标准化商品到深度绑定元件

> HBM4E 阶段，HBM 将不再是标准化商品，而是与 GPU/ASIC **深度绑定的高度客制化元件**。

### 产业权力转移

| 阶段 | 主导者 | 逻辑 |
|------|--------|------|
| 过去 | 存储厂商（DRAM Vendor） | HBM 是标准化零件 |
| 未来 | 晶圆代工 + 系统整合者（台积电、NVIDIA） | 定制化 Base Die 需先进制程 + 异质整合 |

**铁三角联盟雏形**：
- **NVIDIA**（系统设计）
- **台积电**（制造与集成，CoWoS 垄断）
- **SK 海力士**（存体颗粒，HBM 技术领先）

### 对三星的挤压
三星纵有全产业链能力（HBM + GPU die + Base die），但如果每一项都不是顶级：
- 差 HBM + 差 GPU die + 差 Base die
- 「一条龙」服务反而成为负分
- 若逻辑制程和先进封装无法达到顶级水准，难以切入核心客户定制化供应链

### 美光的生存策略
- 体量小 → 稼动率反而更好
- 需尽快绑定台积电或英特尔
- 台积电美国工厂产能陆续开出，从英伟达供应链角度，选择台积电美国厂是大概率

## 六、新秩序：从「三足鼎立」到「一超多强」

### 历史性转折点

**2025 Q2：SK 海力士首次在 DRAM 总营收上超越三星，登顶全球第一。**

这不是偶然。海力士凭借 HBM 的绝对优势，在 AI 时代的存储权力重构中占据了先机。

### 未来格局判断

| 玩家 | 定位 | 关键变量 |
|------|------|---------|
| SK 海力士 | **HBM 王者 + DRAM 营收第一** | 维持技术领先，深化与台积电联盟 |
| 三星 | 最失意者 | 1c nm HBM4 制程、热管理、NV 认证 |
| 美光 | 小而满的幸存者 | 绑定台积电/Intel，推理市场功耗优势 |
| 台积电 | **隐性主导者** | CoWoS 产能 + 定制化 Base Die 先进制程 |
| NVIDIA | 系统定义者 | 绑定海力士+台积电，定义客制化需求 |
