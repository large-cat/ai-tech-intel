### 3. Harness Engineering 认知升级（虎嗅深度长文）

**从 Prompt → Context → Harness 的三阶段演进**：

| 阶段 | 核心 | 时间 |
|---|---|---|
| Prompt Engineering | "说什么" | 2023 |
| Context Engineering | "知道什么" | 2025中 |
| **Harness Engineering** | **"在什么环境里做事"** | **2026-02** |

**OpenAI 实验关键数据**：
- 5名工程师，5个月，**0行手写代码** → 交付100万行生产级代码
- 平均每位工程师每日 **3.5 个 PR** 合并吞吐量
- AGENTS.md 从"把所有信息塞进去"演化为**渐进式披露模型**（精简目录 → 结构化 docs/）

**LangChain 对照实验**：仅优化 Harness，模型不变 → Terminal Bench 2.0 得分 52.8% → 66.5%，排名 第30 → 第5（**最干净的变量控制证据**）

**Böckeler 三级框架**（Thoughtworks）：
1. 上下文工程 — 正确时机获得正确信息
2. 架构约束 — 机械化强制执行边界
3. 熵管理 — 约束系统本身不随时间退化

### 4. 现代 Agentic Harness 架构蓝图（开源设计）

来自 GitHub Gist 的综合架构方案，融合 Anthropic、LangChain/LangGraph、Kimi CLI、MCP、ACP、A2A 官方文档：

**六大核心原则**：
1. Harness 比 loop 重要
2. 围绕缓存稳定性设计
3. 文件系统 = 工作记忆
4. 内置动作空间小而稳定
5. 子Agent 用于上下文隔离
6. guardrails 在运行时而非提示中

**协议三层**：
- **MCP**：Agent → 工具/资源（月 SDK 下载 9,700 万+）
- **ACP**：客户端/IDE → Agent 运行时
- **A2A**：Agent → 远程 Agent

### 5. Flash-MoE：MacBook 跑 397B 参数模型

- 作者：Dan Woods，CVS Health VP of AI Platforms
- 纯 C + Objective-C + 手写 Metal shader
- MacBook Pro M3 Max (48GB RAM) 跑 Qwen3.5-397B-A17B，4.4+ tokens/sec
- 利用 MoE 特性：4/128 专家激活，专家 ~3.9MB，M3 Max SSD 17.5 GB/s
- 209GB 模型全存 SSD，无需 GPU 内存
- HN 核心共识：**非实时批处理场景完全可用**
