## 关键发现

### AI System Demo Zone 展示

#### cHBM (Custom HBM)
- **将GPU/ASIC部分功能集成到HBM基板**
- 客户定制化HBM解决方案
- 信号：客户从"纯性能"转向"推理效率+成本优化"

#### AiMX
- 基于GDDR6-AiM芯片的LLM专用加速器卡
- 面向推理优化

#### CuD (Compute-using-DRAM)
- 在DRAM单元内执行简单计算
- 属于Compute-in-Memory(CIM)方向
- 成熟度：早期阶段

#### CMM-Ax
- CXL内存模块 + 计算能力集成
- 服务器内存扩展+近端计算
- 标准化接口（CXL），兼容现有架构

#### Data-aware CSD
- 可感知/分析/执行处理的计算存储驱动器
- 降低CPU参与，减少数据移动

### 战略信号
- SK海力士正从"内存供应商"转向"Full Stack AI Memory Creator"
- 覆盖HBM → LPDDR → QLC NAND全栈
